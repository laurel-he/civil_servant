非常好。

**通分**是整个考公资料分析、数量关系、概率、差分法、十字交叉法的基础。

很多人知道"通分就是分母变一样"，但不知道**为什么要变一样**。

今天我按照**小学一年级→二年级→三年级……**的方式讲，你学完不仅知道怎么通分，还知道为什么可以通分。

---

# 第一章 什么是分数？

假设有一个蛋糕。

## 第一种切法

切成2份。

```
┌──────┬──────┐
│      │      │
└──────┴──────┘
```

每一份：

```
1/2
```

意思就是：

> **把一个整体平均分成2份，拿其中1份。**

---

## 第二种切法

切成4份。

```
┌───┬───┐
│   │   │
├───┼───┤
│   │   │
└───┴───┘
```

每份：

```
1/4
```

是不是比1/2更小？

因为：

切得更细了。

---

## 分数到底表示什么？

例如：

```
3/5
```

表示：

整个东西

平均分成5份。

拿3份。

这里：

```
3
```

叫：

**分子**

表示：

拿几份。

```
5
```

叫：

**分母**

表示：

平均分成几份。

口诀：

> **分母表示"分几份"，分子表示"拿几份"。**

---

# 第二章 为什么要通分？

来看一个问题。

比较：

```
1/2

和

2/3
```

谁大？

很多人第一反应：

不知道。

为什么？

因为：

一个是：

平均分2份。

一个是：

平均分3份。

标准不一样。

就像：

一个人说：

```
我跑了10公里。
```

另一个人说：

```
我跑了6英里。
```

谁跑得远？

不能直接比较。

因为：

单位不同。

必须统一单位。

公里↔英里。

---

分数也是一样。

必须：

> **统一分母。**

这就是：

**通分。**

---

# 第三章 什么叫通分？

例如：

```
1/2
```

如果：

把整个蛋糕重新切。

原来：

```
2份
```

现在：

变：

```
6份
```

是不是每份更小了？

原来的：

```
1/2
```

其实变成：

```
3/6
```

画图：

原来：

```
┌────┬────┐
│■■■■│□□□□│
└────┴────┘
```

现在：

每一块继续切三刀。

```
┌──┬──┬──┬──┬──┬──┐
│■ │■ │■ │□ │□ │□ │
└──┴──┴──┴──┴──┴──┘
```

是不是：

还是原来那么大？

只是：

表示方式不同。

所以：

```
1/2

=

3/6
```

# 第四章 为什么可以同时乘3？

很多人死记：

```
分子乘3

分母乘3
```

其实根本不知道为什么。

来看。

原来：

```
1/2
```

就是：

一个整体。

平均两份。

拿一份。

现在：

每一份

再切3刀。

于是：

总份数：

```
2×3=6
```

拿的那一半

是不是也变成：

```
1×3=3
```

于是：

```
3/6
```

所以：

分子、

分母

必须一起乘。

---

数学上：

```
1/2

=

1×3

──────

2×3
```

=

```
3/6
```

为什么？

因为：

```
3÷6
```

和：

```
1÷2
```

都是：

```
0.5
```

值没有变。

---

# 第五章 为什么不能只乘分母？

例如：

有人写：

```
1/2

=

1/6
```

错。

为什么？

看看数字。

```
1/2

=

0.5
```

而：

```
1/6

≈0.166
```

已经不是一个数了。

相当于：

把蛋糕变小了。

---

同理：

不能只乘分子。

```
3/2
```

=

1.5

不是：

```
1/2
```

---

口诀：

> **分子分母必须同时乘（或同时除）同一个非零数。**

这样：

分数大小才不会变。

---

# 第六章 怎样通分？

来看：

```
1/2

和

1/3
```

目标：

分母一样。

2和3

最小共同倍数：

```
6
```

于是：

第一个：

```
1/2

=

3/6
```

第二个：

```
1/3

=

2/6
```

现在：

直接比较：

```
3/6

>

2/6
```

所以：

```
1/2

>

1/3
```

# 第七章 为什么找最小公倍数？

例如：

2和3

共同倍数：

```

18

24
```

例如：

通成：

```

```

为什么一般不用12？

因为：

计算越来越麻烦。

所以：

找：

> **最小公倍数。**

# 第九章 公务员考试真的会通分吗？

会。

例如：

比较：

```
31/67

29/63
```

小学：

通分。

```
31×63

29×67
```

但是：

太慢。

所以：

公务员才发明：

**差分法。**

差分法其实就是：

> **通分的快速替代方法。**

因为：

```
31×63

29×67
```

乘法太耗时间。

所以：

资料分析几乎不用真正通分。

但是：

必须理解通分。

否则：

根本不知道差分法为什么成立。

# 第十章 通分与交叉相乘有什么关系？

例如：

比较：

```
3/5

4/7
```

小学：

通分：

35。

得到：

```
21/35

20/35
```

所以：

```
3/5

>

4/7
```

另一种方法：

直接交叉：

```
3×7

=

21
```

```
4×5

=

20
```

也是：

21>20。

为什么一样？

因为：

交叉相乘其实就是：

**把通分过程省略了。**

---

# 第十一章 今天真正要记住的东西

不要背"通分公式"，而是理解这五句话：

1. **分母不同，不能直接比较大小。**
2. **通分就是统一比较标准，就像统一长度单位一样。**
3. **通分时，分子和分母必须同时乘（或同时除）同一个非零数。**
4. **分数值不会因为同时乘（或除）同一个非零数而改变。**
5. **公务员考试很少直接通分，但差分法、交叉相乘法、本质上都是由通分推导出来的。**

## 接下来建议的学习顺序

按照真正的数学逻辑，建议依次学习：

1. **分数的意义**（今天）
2. **约分**（为什么可以同时除）
3. **通分**（今天）
4. **交叉相乘**（为什么不用真正通分）
5. **差分法**（为什么新增平均可以比较）
6. **截位直除法**
7. **插值法**
8. **十字交叉法**

这条路线是从最基础的数学原理逐步推导到考公速算技巧，而不是死记各种方法，因此后面学习资料分析会轻松得多。
