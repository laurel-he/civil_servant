非常好，**截位直除法**是考公资料分析里最重要的速算技巧，没有之一。

但是，**99%的老师一上来就讲"截三位、截两位"**，很多人学完还是不会，因为他们跳过了最重要的一步——**为什么可以截位？**

我会按照**小学数学 → 原理 → 技巧 → 真题**的顺序，从零开始教。

---

# 第一章 什么是除法？

先回到小学。

例如：

```
12 ÷ 3 = 4
```

什么意思？

不是"12里面有几个3"。

真正的意思是：

> **把12平均分成3份，每份是多少。**

例如：

```
🍎🍎🍎🍎🍎🍎🍎🍎🍎🍎🍎🍎

↓

3个人分

↓

每人4个
```

---

再例如：

```
40 ÷ 5
```

就是：

40平均分给5个人。

答案：

```
8
```

---

## 练习

```
90 ÷ 9
```

平均分。

答案：

```
10
```

这是除法最本质的含义。

---

# 第二章 为什么可以估算？

来看一道题。

```
398 ÷ 100
```

大家不用算。

都知道：

```
≈4
```

为什么？

因为：

398离400很近。

```
400÷100=4
```

所以：

398÷100

一定非常接近4。

这就是：

> **估算。**

资料分析95%的计算都是估算。

不是算精确值。

# 第三章 什么叫截位？

例如：

```
2987÷603
```

正常算：

很麻烦。

怎么办？

观察：

```
2987
```

其实：

```
≈3000
```

603

其实：

```
≈600
```

于是：

```
3000÷600
```

=

```
5
```

答案就出来了。

这就是：

> **截位。**

什么意思？

就是：

> **舍弃最后几位，只保留最重要的数字。**

---

例如：

```
2987
```

截位以后：

```
3000
```

603

变成：

```
600
```

然后直接计算。

---

# 第四章 为什么可以这样做？

这是很多老师不会讲的。

其实：

```
2987
```

和

```
3000
```

差多少？

只差：

```
13
```

占3000：

```
13÷3000

≈0.4%
```

误差不到1%。

603

变600。

差：

```
3
```

占600：

```
0.5%
```

误差也不到1%。

所以：

最后答案误差：

不到2%。

公务员四个选项一般相差10%以上。

所以：

根本不会影响答案。

# 第五章 截位原则

这是考公必须牢记的。

## 原则一

**看选项差距。**

例如：

```
A 4%

B 8%

C 13%

D 21%
```

差距特别大。

大胆截位。

---

如果：

```
A 11.2%

B 11.8%

C 12.1%

D 12.4%
```

不能随便截。

需要多保留一位。

# 第十一章 考公真正考法

例如：

今年收入：

```
382亿元
```

去年：

```
298亿元
```

问：

增长率。

公式：

```
(382-298)÷298
```

=

```
84÷298
```

不用算。

直接：

```
84≈90

298≈300
```

于是：

```
90÷300

=

30%
```

实际：

```
28%
```

选项：

```
A 18%

B 28%

C 37%

D 51%
```

直接选：

28%。

---

# 第十二章 截位口诀（必须背）

第一句：

> **选项差距大，大胆截位。**

第二句：

> **保留最高位，舍弃最低位。**

第三句：

> **先截位，再直除。**

第四句：

> **资料分析不是算数学，是排除选项。**

# 第十三章 为什么有时不能截？

例如：

```

```

如果：

```
1000÷500

=

2
```

实际：

```
1.98
```

还可以。

---

但是：

```
549÷498
```

如果：

```
500÷500

=

1
```

实际：

```
1.102
```

误差已经超过10%。

如果选项：

```

1.08

1.11

1.15
```

就会选错。

所以：

> **选项越接近，截位越少。**

# 学完这一课后，下一步应该学什么？

我建议按照真正的考公学习路线，而不是零散技巧：

**第一册：《考公数学基础》**

1. 九九乘法表与乘除法规律
2. 分数、小数、百分数互化
3. 估算与凑整
4. 截位直除法（今天这一章）
5. 首数法
6. 尾数法
7. 差分法
8. 插值法
9. 十字交叉法

然后再进入**资料分析**（现期、基期、增长率、比重等）。

这样你不仅知道"怎么做"，更知道"为什么这么做"，后面学起来会轻松很多。
