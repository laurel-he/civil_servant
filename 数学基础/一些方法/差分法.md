很好，**差分法**是资料分析里公认**最难理解、但最好用**的速算技巧之一。

很多老师上来就告诉你：

> "两分数比较大小，作差分。"

然后开始讲公式，学生一脸懵。

**今天我们不用任何公式，从小学数学开始，一步一步推导，让你知道为什么会有差分法。**

---

# 第一章 为什么需要差分法？

先看一道小学题。

比较：

```text
3/5 和 4/5
```

谁大？

大家都会。

因为：

分母一样。

只比较分子。

```
4 > 3
```

所以：

```
4/5 > 3/5
```

这是小学知识。

---

再看：

```text
3/7 和 3/5
```

谁大？

分子一样。

分母越小，

平均分越少，

每份越大。

所以：

```
3/5 > 3/7
```

这也是小学知识。

---

但是公务员考的是：

```
31/67

29/63
```

怎么办？

分子不同。

分母不同。

不能直接比较。

---

# 第二章 小学方法——通分

小学老师教的方法：

```
31×63

=

1953
```

```
29×67

=

1943
```

因为：

```
1953>1943
```

所以：

```
31/67

>

29/63
```

这是完全正确的。

---

但是……

公务员考试只有：

**120分钟135题。**

谁有时间算：

```
31×63

29×67
```

所以：

需要更快的方法。

---

# 第三章 我们观察规律

来看几组数。

第一组：

```
20/100

21/100
```

第二个大。

为什么？

因为：

多了1。

---

第二组：

```
50/100

51/100
```

第二个也大。

还是：

多了1。

---

第三组：

```
90/100

91/100
```

也是第二个大。

---

你会发现：

**决定大小的，其实不是"1"，而是"1占100有多大"。**

例如：

```
1÷100

=

1%
```

---

# 第四章 引入"差"

来看：

```
51/100
```

比：

```
50/100
```

大多少？

其实就是：

```
1/100
```

这个：

```
1/100
```

就是：

**差。**

以后：

差分法里的"差"，

就是这个意思。

---

# 第五章 再来看公务员题

比较：

```
31/67

29/63
```

不要急着通分。

先观察。

分子：

```
31

29
```

只差：

```
2
```

分母：

```
67

63
```

也差：

```
4
```

是不是差得都很小？

这时候，

真正决定大小的，

就是：

**到底增加的分子快，

还是增加的分母快。**

---

# 第六章 为什么叫差分？

来看：

```
31/67
```

如果变成：

```
29/63
```

需要怎么变？

分子：

```
29

+

2

=

31
```

分母：

```
63

+

4

=

67
```

于是：

增加了：

```
2/4
```

这个：

```
2÷4

=

50%
```

就叫：

**差分。**

很多书写成：

```
分子差

÷

分母差
```

即：

```
(31-29)

÷

(67-63)

=

2÷4

=

50%
```

---

# 第七章 为什么要算这个？

这里才是真正的原理。

原来的分数：

```
29/63
```

约等于：

```
46%
```

而：

新增部分：

```
2/4

=

50%
```

注意：

新增部分：

50%

比原来：

46%

更高。

说明：

你新增进去的部分，

"质量更高"。

那么：

整体平均一定会上升。

所以：

```
31/67

>

29/63
```

是不是不用乘法了？

---

# 第八章 举生活例子

这是理解差分法最容易的方法。

假设：

63个人。

平均分：

```
29分
```

现在：

来了4个人。

这4个人平均：

```
50分
```

问：

全班平均会上升还是下降？

当然：

上升。

因为：

新来的平均：

```
50
```

高于原来的：

```
29÷63≈46%
```

所以：

整个平均提高。

于是：

```
31/67

>

29/63
```

---

# 第九章 什么时候比较差分？

口诀：

**新增平均**

和

**原来平均**

比较。

---

如果：

新增平均

>

原来平均

整体提高。

---

如果：

新增平均

<

原来平均

整体下降。

---

# 第十章 真正公式来了

现在你已经理解了。

公式其实只有一句：

设：

```
A/B

和

C/D
```

比较。

先算：

```
差分

=

(A-C)

÷

(B-D)
```

然后：

比较：

```
差分

和

原来的分数
```

如果：

```
差分>

原来
```

那么：

```
A/B

>

C/D
```

如果：

```
差分<

原来
```

那么：

```
A/B

<

C/D
```

---

# 第十一章 真题

例如：

```
103/205

101/201
```

先算：

差：

```
2

4
```

差分：

```
2÷4

=

50%
```

原来：

```
101÷201

≈50.2%
```

比较：

```
50%

<

50.2%
```

说明：

新增的人，

比原来平均低。

于是：

整体下降。

所以：

```
103/205

<

101/201
```

不用乘法。

几秒完成。

---

# 第十二章 为什么国考喜欢考？

因为很多题都是：

```
520

/

1020
```

和

```
510

/

1000
```

这种。

直接通分：

```
520×1000
```

太慢。

而差分：

```
10÷20

=

50%
```

秒做。

---

# 第十三章 考公真正的使用条件（这是很多老师不讲的）

**差分法不是万能的，它只适合下面这种情况：**

✅ 分子、分母都很接近。

例如：

```
312/678

309/671
```

或者：

```
103/205

101/201
```

因为：

差值很小，

新增部分很好算。

---

如果：

```
87/102

12/35
```

千万不要用差分。

直接通分、

截位、

直除更快。

---

# 最后送你一个记忆口诀

不要死记公式，只记下面四句话：

> **第一步：看两个分数是否接近。**

> **第二步：算分子差、分母差。**

> **第三步：用"分子差÷分母差"得到新增平均。**

> **第四步：新增平均和原来平均比较，新增平均高，整体就高；新增平均低，整体就低。**

## 我建议的学习路线

如果我们真的要把资料分析从零学透，我会按一本教材来讲，而不是零散技巧：

1. 小学数学（运算规律）
2. 分数与百分数
3. 估算思想
4. 截位直除法
5. **差分法（为什么能用，而不是只会公式）**
6. 插值法
7. 十字交叉法
8. 比重、增长率、平均数等资料分析题型

这样你不仅能会做题，还能理解每一种技巧背后的数学原理。
