# 第九章：高级差分法（国考、省考高频技巧）

> **重要程度：⭐⭐⭐⭐⭐（必须掌握）**

本章学完后，你将能够：

* 比较两个复杂分数大小
* 不通分、不计算小数
* 5 秒内完成很多国考真题
* 理解为什么差分法成立，而不是死记口诀

---

# 第一节 为什么需要高级差分法？

来看一道真题类型：

比较：

[
\frac{126}{358}
]

和

[
\frac{128}{365}
]

大小。

很多同学第一反应：

计算器。

第二反应：

通分。

实际上考试中都来不及。

---

# 第二节 为什么通分不可行？

通分：

358×365

你会得到：

130670

然后：

126×365

128×358

……

考试中基本不现实。

所以：

必须换方法。

---

# 第三节 从最简单的例子开始

先看：

[
\frac{10}{20}
]

和

[
\frac{11}{22}
]

其实：

都等于

1/2。

为什么？

因为：

分子分母同时增加了：

10%。

比例没变。

---

再看：

[
\frac{10}{20}
]

和

[
\frac{11}{20}
]

显然：

第二个更大。

因为：

分母一样。

分子变大。

---

再看：

[
\frac{10}{20}
]

和

[
\frac{10}{22}
]

显然：

第二个更小。

因为：

分子一样。

分母变大。

---

这些都是小学知识。

---

# 第四节 真正困难的情况

例如：

[
\frac{126}{358}
]

和

[
\frac{128}{365}
]

发现：

分子变了。

分母也变了。

怎么办？

---

# 第五节 差分法核心思想

先假设：

我们把：

[
\frac{126}{358}
]

变成：

[
\frac{128}{358}
]

这样：

分子增加：

2。

所以：

分数变大。

然后：

再变成：

[
\frac{128}{365}
]

分母增加：

7。

所以：

分数变小。

于是问题来了：

> **到底是分子增加2影响大，还是分母增加7影响大？**

这就是高级差分法研究的问题。

---

# 第六节 数学推导（从零开始）

设：

第一个分数：

[
\frac{A}{B}
]

第二个：

[
\frac{A+a}{B+b}
]

其中：

* 分子增加 a
* 分母增加 b

我们想知道：

哪个更大。

直接比较：

[
\frac{A+a}{B+b}
---------------

\frac{A}{B}
]

通分：

# [

\frac{(A+a)B-A(B+b)}
{B(B+b)}
]

展开：

# [

\frac{AB+aB-AB-Ab}
{B(B+b)}
]

AB消掉：

得到：

# [

\frac{aB-Ab}
{B(B+b)}
]

提取公因数：

# [

\frac{aB-bA}
{B(B+b)}
]

---

## 最关键的一步

因为：

分母：

[
B(B+b)
]

一定大于0。

所以：

真正决定大小的是：

[
aB-bA
]

这就是：

**高级差分法的数学本质。**

---

# 第七节 如何使用？

来看刚才那道题：

[
\frac{126}{358}
]

和

[
\frac{128}{365}
]

先找：

a

=

2

b

=

7

然后：

计算：

[
2×358
]

=

716

再算：

[
7×126
]

=

882

比较：

716

<

882

所以：

[
aB-bA<0
]

说明：

第二个分数

更小。

所以：

[
\frac{126}{358}

>

\frac{128}{365}
]

不用通分。

---

# 第八节 为什么这样理解？

其实：

分子：

增加：

2

相当于：

"加分"

分母：

增加：

7

相当于：

"减分"

如果：

加分

>

减分

分数变大。

否则：

变小。

---

# 第九节 再做几题

---

## 例1

比较：

[
\frac{200}{500}
]

和

[
\frac{205}{510}
]

a=5

b=10

计算：

5×500

=2500

10×200

=2000

2500>2000

所以：

第二个更大。

验证：

200/500=0.4

205/510≈0.402

正确。

---

## 例2

比较：

[
\frac{300}{800}
]

和

[
\frac{302}{810}
]

a=2

b=10

计算：

2×800=1600

10×300=3000

1600<3000

第二个更小。

---

# 第十节 真题做法（国考常见）

很多题：

其实不是让你算。

而是：

比较：

甲增长率

乙增长率

最后都会变成：

比较两个分数。

例如：

[
\frac{15}{82}
]

和

[
\frac{18}{96}
]

直接：

高级差分。

不用通分。

---

# 第十一节 什么情况下不能用？

注意：

高级差分法有一个前提：

两个分数：

**非常接近。**

例如：

[
\frac{10}{20}
]

和

[
\frac{90}{100}
]

没必要。

直接看：

0.5

和

0.9

即可。

---

# 第十二节 易错点

---

## 错误①

a

算错。

一定是：

第二个分子

减

第一个分子。

---

## 错误②

b

方向反。

一定：

第二个分母

减

第一个分母。

---

## 错误③

比较符号写反。

记住：

如果：

[
aB>bA
]

第二个分数更大。

---

# 第十三节 一个万能口诀（帮助记忆）

设：

[
\frac{A}{B}
]

变成：

[
\frac{A+a}{B+b}
]

只计算：

> **分子增加 × 原分母**

和

> **分母增加 × 原分子**

如果：

```text
a × B

>

b × A
```

第二个分数更大。

否则：

更小。

---

# 本章总结

真正要记住的只有一个公式：

[
aB-bA
]

但**不要死记**。

请记住它是怎么推导出来的：

1. 两个分数作差；
2. 通分；
3. 展开；
4. 消掉 AB；
5. 得到：

[
aB-bA
]

这样考试时就算忘了公式，也能自己推出来。

# ⚠️ 最后，我要纠正前面教程中的一个重要问题

到目前为止，我们已经学了：

* 特殊分数
* 截位直除法
* 基础差分法
* 高级差分法

**但是，真正的国考资料分析并不是按照这个顺序使用技巧的。**

实际做题时，思考顺序通常是：

```text
看到题目
     │
     ▼
① 判断题型
（增长？比重？平均？倍数？）

     │
     ▼
② 判断是否需要计算

     │
     ▼
③ 看选项间距

     │
     ├── 选项差距大 → 截位直除  
     │
     ├── 比较两个分数 → 高级差分法
     │
     ├── 接近特殊分数 → 特殊分数速判
     │
     └── 选项特别接近 → 精确计算
```

很多教材是一种技巧讲完再讲下一种，但**考试时不是按章节，而是按题型和选项来选择方法**。
