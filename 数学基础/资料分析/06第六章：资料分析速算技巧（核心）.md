# 第六章：资料分析速算技巧（第一节：特殊分数）

> **重要程度：⭐⭐⭐⭐⭐（资料分析提速核心）**

很多同学一开始就学**截位直除法**，结果越学越乱。

实际上，真正的学习顺序应该是：

> **特殊分数 → 百分数转换 → 截位直除 → 差分法 → 插值法**

为什么？

因为截位直除时，你必须知道：

```
1/2≈50%
1/3≈33%
2/3≈67%
```

否则即使算出来也不知道选哪个答案。

---

# 第一节 为什么先学特殊分数？

看一道国考题。

```
726÷242≈？
```

不用列竖式。

看到：

```
242×3=726
```

立即知道：

```
726÷242

=3
```

这不需要速算。

但是：

```
242÷726≈？
```

怎么办？

如果知道：

```
1/3≈33%
```

立即知道：

```
242÷726≈33%
```

所以：

> **特殊分数，是资料分析所有速算的基础。**

# 第五节 怎么快速记？

很多人选择死背。

其实不用。

例如：

知道：

```
1/8

=

12.5%
```

那么：

```
3/8

=

12.5×3

=

37.5%
```

马上得到。

再例如：

知道：

```
1/7≈14.3%
```

那么：

```
6/7

=

100%

-

14.3%

=

85.7%
```

所以：

很多分数都能推出来。

# 第七节 考试中的应用

例如：

```
84÷336
```

看到：

```
84×4=336
```

马上：

```
84÷336

=

1/4

=

25%
```

不用计算。

---

例如：

```
198÷660
```

约等于：

```
200÷600

=

1/3

≈33%
```

答案立即出来。

---

再例如：

```
125÷1000
```

看到：

```
1/8

=

12.5%
```

所以：

```
125÷1000

=

12.5%
```

# 第十节 最容易错的地方

例如：

```
660÷2000
```

很多人看到：

```
660≈2/3
```

就写：

66%。

这是错误的。

应该先约分：

```
660÷2000

=

33%
```

**一定要看分母是多少。**

# 本节总结

今天只学了一个知识点：

> **特殊分数。**

但这是资料分析所有速算技巧的基础。如果这个基础不牢，后面的**截位直除法、差分法、插值法**都会受到影响。
