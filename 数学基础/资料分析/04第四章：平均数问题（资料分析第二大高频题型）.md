# 第四章：平均数问题（资料分析第二大高频题型）

> **重要程度：⭐⭐⭐⭐⭐（国考、省考几乎每年必考）**
>
> 平均数题看似简单，但很多考生会把**平均数、比重、增长率**混淆。
>
> **学完本章，你应该能够：**
>
> * 理解平均数的本质。
> * 熟练解决"人均""户均""车均""企均"等问题。
> * 掌握平均数增长问题。
> * 区分平均数、比重、增长率。

---

# 第一节 什么是平均数？

平均数就是：

> **总量平均分给每一个单位。**

例如：

班里有4名同学，成绩分别是：

80、90、70、60

总分：

80+90+70+60=300

平均分：

300÷4=75

所以：

**平均数 = 总量 ÷ 个数**

---

## 再举一个生活例子

一个月工资：

17000元

工作22天

平均每天收入：

17000÷22≈773元

这里：

773元就是平均数。

---

# 第二节 平均数公式

所有平均数题都遵循一个公式：

> **平均数 = 总量 ÷ 单位数**

例如：

销售额：

120亿元

企业数量：

400家

平均每家企业销售额：

120÷400

=0.3亿元

# 第五节 平均数和比重有什么区别？

很多同学容易混淆。

来看一个例子。

某市：

人口：

100万人

GDP：

500亿元

工业：

200亿元

问：

人均GDP？

500÷100

=5万元

这是：

平均数。

如果问：

工业占GDP多少？

200÷500

=40%

这是：

比重。

区别：

| 类型  | 分母是什么？        |
| --- | ------------- |
| 平均数 | 单位数量（人、户、企业等） |
| 比重  | 总体总量          |

---

# 第六节 平均数和增长率有什么区别？

例如：

去年：

工资100元

今年：

工资120元

平均工资：

120元

增长率：

(120−100)÷100

=20%

平均工资：

是一个"数值"

增长率：

是一个"速度"

不能混淆。

---

# 第七节 平均数增长问题（重点）

这是考试高频。

例如：

今年：

销售额：

240亿元

增长20%

企业数量：

100家

增长25%

问：

平均每家企业销售额增加还是减少？

第一步：

今年平均：

240÷100

=2.4

第二步：

去年销售额：

240÷1.2

=200

去年企业：

100÷1.25

=80

去年平均：

200÷80

=2.5

今年：

2.4

去年：

2.5

所以：

平均数下降。

---

# 第八节 一个重要规律（必须掌握）

平均数由两个因素决定：

> **平均数 = 总量 ÷ 单位数**

因此：

* 总量增长快于单位数 → 平均数增加
* 单位数增长快于总量 → 平均数减少
* 增长速度相同 → 平均数基本不变

例如：

收入增长20%

人口增长10%

那么：

人均收入会上升。

反过来：

收入增长10%

人口增长20%

那么：

人均收入会下降。

# 第十一节 易错点

## 错误①

把平均数当比重

例如：

GDP÷人口

不是比重。

而是平均数。

---

## 错误②

单位忘记换算

例如：

收入：

480亿元

人数：

12000人

答案：

400万元/人？

错。

应该认真统一单位。

480亿元

=4800000万元

再计算。

---

## 错误③

平均数增长≠总量增长

例如：

收入增长20%

人口增长18%

平均收入：

增长不到20%。

因为：

人口也增加了。

# 第十二节 高频考点总结

| 考点      | 公式           | 考频    |
| ------- | ------------ | ----- |
| 求平均数    | 总量÷单位数       | ⭐⭐⭐⭐⭐ |
| 求总量     | 平均数×单位数      | ⭐⭐⭐   |
| 求单位数    | 总量÷平均数       | ⭐⭐⭐   |
| 平均数增长   | 比较两期平均数      | ⭐⭐⭐⭐⭐ |
| 平均数变化判断 | 比较总量与单位数增长速度 | ⭐⭐⭐⭐  |
