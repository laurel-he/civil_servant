# 第七章：截位直除法（资料分析第一神技）

> **重要程度：⭐⭐⭐⭐⭐（必学）**
>
> 如果说资料分析有一种技巧能够让你从 **30 秒一题变成 5～10 秒一题**，那就是**截位直除法**。
>
> **国考、省考资料分析中，80% 以上的除法都可以使用。**

---

# 第一节 什么是截位直除法？

先看一道题。

```
3268 ÷ 812
```

很多人会：

* 列竖式
* 拿草稿纸
* 算半天

实际上考试中根本没时间。

我们观察：

```
3268≈3200

812≈800
```

于是：

```
3200÷800

=4
```

真正答案：

```
3268÷812

≈4.02
```

考试选项如果是：

```
A.2.8

B.4.0

C.5.3

D.6.1
```

直接选：

> **B**

整个过程不到5秒。

这就是：

> **截位直除法**

---

# 第二节 什么叫"截位"？

很多人理解错了。

**截位不是随便删数字。**

例如：

```
3289
```

不能变成：

```
38
```

也不能变成：

```
329
```

而应该：

保留前几位。

例如：

```
3289

↓

3300
```

或者：

```
3280
```

都可以。

---

例如：

```
817
```

可以变成：

```
820
```

或者：

```
800
```

---

所以：

> **截位=保留最高位（或前两位），舍去后面的数字，并进行适当四舍五入。**

---

# 第三节 为什么可以截位？

因为：

公务员考试几乎都是：

**选择题。**

例如：

真正计算：

```
3268÷812

=4.0246……
```

选项：

```
A.2.9

B.4.0

C.5.2

D.6.4
```

你根本不需要算到：

```
4.024630541871921……
```

知道：

约等于4

就够了。

---

# 第四节 第一步：先看选项

这是最重要的一步。

很多教材直接开始截位。

这是错误的。

正确顺序：

```
第一步：

看选项。
```

例如：

```
A.31%

B.32%

C.48%

D.66%
```

差距：

非常大。

可以大胆截。

---

再例如：

```
A.31.2%

B.31.5%

C.31.8%

D.32.1%
```

四个选项只差：

0.3%。

这时候：

不能粗略截位。

否则一定错。

---

所以：

> **先看选项，再决定截多少位。**

---

# 第五节 第二步：判断截几位

这是整个方法的核心。

## 第一种

选项差距：

大于5%

例如：

```
20%

35%

50%

80%
```

保留：

一位数字即可。

例如：

```
3879≈4000

821≈800
```

---

## 第二种

选项差距：

2%左右。

例如：

```
31%

33%

35%

37%
```

建议：

保留两位。

例如：

```
3879≈3900

821≈820
```

---

## 第三种

选项差：

不到1%。

例如：

```
31.2%

31.5%

31.7%

31.9%
```

必须：

保留三位。

甚至不用截位。

---

## 口诀

```
选项差越大

截得越狠

选项差越小

保留越多
```

---

# 第六节 第三步：同时截

很多同学犯一个错误。

例如：

```
3876÷823
```

只截一个。

变成：

```
3900÷823
```

这是不规范。

应该：

```
3900÷820
```

这样误差更稳定。

---

# 第七节 第四步：利用特殊分数

例如：

```
390÷780
```

看到：

```
390×2=780
```

立即：

```
1/2

=

50%
```

---

例如：

```
405÷810
```

一样：

```
50%
```

---

例如：

```
260÷780
```

约：

```
1/3

≈33%
```

---

例如：

```
600÷800
```

立即：

```
3/4

=

75%
```

所以：

> **截位的最终目的，是把数字变成熟悉的特殊分数。**

---

# 第八节 真题例子（基础）

例1：

```
648÷1612
```

第一步：

截位。

```
650÷1600
```

第二步：

约分。

```
65÷160
```

继续：

```
13÷32
```

知道：

```
12.8÷32

=40%
```

所以：

约：

40%。

真正答案：

40.2%。

---

## 例2

```
986÷1988
```

截位：

```
1000÷2000
```

立即：

```
50%
```

真正答案：

49.6%。

---

## 例3

```
720÷1800
```

看到：

```
72÷180

=

2÷5

=

40%
```

不用任何计算。

# 第九节 什么时候不能截？

这是考试最容易掉坑的地方。

例如：

```
A.48.1%

B.48.3%

C.48.5%

D.48.7%
```

如果：

```
965÷2005
```

直接：

```
1000÷2000

=

50%
```

一定错。

因为：

真实答案：

48.1%。

这里必须精算。

---

## 原则

> **选项越接近，越不能粗截。**

# 第十一节 常见错误

## 错误①

只截分子。

错误：

```
3900÷823
```

正确：

```
3900÷820
```

---

## 错误②

乱四舍五入。

例如：

```
1499
```

有人：

变成：

1000。

这是错误。

应该：

1500。

---

## 错误③

不看选项。

这是最大错误。

很多教材没有强调这一点。

真正考试：

**选项决定算法。**

# 第十二节 四步法（必须背）

以后所有截位题：

统一流程。

```
第一步：

看选项。

↓

第二步：

决定截几位。

↓

第三步：

分子分母一起截。

↓

第四步：

转换成特殊分数。
```

做到这四步，你已经能解决大多数资料分析中的除法题。

# 一个非常重要的补充（很多教材不会讲）

很多机构会说：

> **"截位直除法就是四舍五入。"**

这是不准确的。

**截位直除法的本质不是四舍五入，而是"控制误差"。**

例如：

```
998 ÷ 2005
```

可以近似成：

```
1000 ÷ 2000
```

因为：

* 分子变大了一点（约 +0.2%）
* 分母变小了一点（约 -0.25%）

误差仍然很小，可以接受。

但是如果写成：

```
900 ÷ 2000
```

误差已经超过 10%，就可能导致选错答案。

因此，**判断能不能截、截多少位，不是固定规则，而是根据选项间距来控制误差**。这是很多考生真正需要建立的思维。
