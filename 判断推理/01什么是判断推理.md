# 一、判断推理到底考什么？

判断推理通常可以分成 **4 大模块**：

| 模块       | 常见题型            | 核心能力 | 学习难度 |
| -------- | --------------- | ---- | ---- |
| **图形推理** | 规律类、位置类、数量类、属性类 | 找规律  | ⭐⭐⭐  |
| **定义判断** | 给定义选符合/不符合      | 精准匹配 | ⭐⭐   |
| **类比推理** | A:B = C:?       | 找关系  | ⭐⭐   |
| **逻辑判断** | 推理、论证、真假话、集合等   | 逻辑分析 | ⭐⭐⭐⭐ |

如果按照四川省考/国考的实际备考价值来看，我建议：

> **定义判断 → 类比推理 → 图形推理 → 逻辑判断**

但逻辑判断最后要投入最多时间。

# 三、我们正式开始：第一章

# 第1章：什么是判断推理？

先不要急着做题。

你需要建立一个最重要的意识：

> **判断推理不是考“聪明”，而是考你能不能找到题目中的结构。**

比如：

### 题目

> 小王是四川人。

这句话本身没有复杂逻辑。

但是：

> 所有四川人都会说四川话。
> 小王是四川人。
> 因此，小王会说四川话。

这里就出现了一个结构：

```text
所有A都是B
小王是A
↓
小王是B
```

以后我们做大量题，本质上就是：

> **识别结构。**

---

# 四、判断推理最重要的第一能力：识别题型

# 五、第一大模块：定义判断

我们先从最容易入门的开始。

## 1. 什么是定义判断？

题目给你一个定义：

> **行政处罚：行政机关依法对违反行政管理秩序的公民、法人或者其他组织，以减损权益或者增加义务的方式予以惩戒的行为。**

然后给你四个选项。

问：

> 下列属于行政处罚的是：

你的任务不是判断：

> “这个事情现实中是不是行政处罚？”

而是：

> **这个选项是否满足题目给出的定义。**

这是一个非常重要的区别。

---

# 六、定义判断的核心公式

以后看到一个很长的定义，不要整句话硬读。

把它拆成：

> **主体 + 对象 + 条件 + 方式 + 目的 + 结果**

例如：

> 行政处罚是行政机关依法对违反行政管理秩序的公民、法人或者其他组织，以减损权益或者增加义务的方式予以惩戒的行为。

可以拆成：

| 要素 | 内容         |
| -- | ---------- |
| 主体 | 行政机关       |
| 对象 | 公民、法人、其他组织 |
| 前提 | 违反行政管理秩序   |
| 方式 | 减损权益/增加义务  |
| 目的 | 惩戒         |
| 性质 | 行政行为       |

于是我们就得到：

```text
行政机关
   ↓
对象违反行政管理秩序
   ↓
减损权益 / 增加义务
   ↓
进行惩戒
```

选项只要缺一个关键条件，就可能不是。

---

# 七、定义判断最重要的技巧：抓“硬条件”

例如：

> **犯罪预备**：为了犯罪，准备工具、制造条件，但由于行为人意志以外的原因而未能着手实行犯罪的行为。

里面有几个关键条件：

### 条件1

> 为了犯罪

### 条件2

> 准备工具、制造条件

### 条件3

> 尚未着手实行犯罪

### 条件4

> 因意志以外原因

可以简化：

```text
犯罪预备
=
为了犯罪
+
准备工具/制造条件
+
尚未着手
+
意志以外原因
```

如果某个选项：

> 某人已经开始实施犯罪，但是因为害怕而主动停止。

那么即使它看起来“很像犯罪预备”，也不能选。

因为：

> **已经着手实行犯罪**

不符合定义。

---

# 八、定义判断的“关键词陷阱”

这是你以后必须特别注意的。

比如定义：

> A是**通过某种方式**达到某种目的的行为。

选项可能写：

> 某人达到了这个目的。

但没有：

> 通过规定的方式。

那么不能直接选。

因为：

> **结果相同 ≠ 定义相同**
