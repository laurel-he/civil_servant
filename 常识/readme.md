### 对你来说，我更推荐下一步这样学

你之前已经在系统学**资料分析、速算、公式、成语等**，所以常识也不要采用“今天刷50道、明天刷50道”的方式。

可以直接做成一套：

> **《考公常识从零开始》**

按照：

**政治 → 历史 → 法律 → 地理 → 科技 → 生物 → 经济 → 文学 → 文化 → 环境 → 生活常识**

逐章学习。

每一章再按照：

> **基础知识 → 高频考点 → 易混淆点 → 常见陷阱 → 真题 → 记忆口诀 → 小测验**

来学。

这样最终会形成一套比较完整的**考公常识知识库**，而不是零散地背题。
