# 第一节 为什么要学习凑整法

## 一、什么是凑整法？

凑整法，是考公数量关系和资料分析中最重要的速算技巧。

所谓"凑整"，就是**主动把不好计算的数字，转换成容易计算的数字，再进行修正**。

例如：

> 398 × 51

普通算法：

```
398
× 51
------
398
19900
------
20298
```

需要十几秒。

而凑整法：

```
398≈400

400×51=20400

减去2×51

20400-102

=20298
```

整个过程通常只需3～5秒。

**考场上，你不是在和数学较劲，而是在和时间较劲。**

---

## 二、为什么公务员考试特别强调凑整？

公务员考试有两个特点：

### 特点一：数字故意设计得“不舒服”

例如：

```

```

为什么不是：

```

```

因为命题人知道，大多数考生看到这些数字就会开始列竖式。

而真正考察的是：

> 你是否能够迅速发现它们距离整数只有一步之遥。

---

### 特点二：大多数题并不需要精确计算

例如：

```

```

```

```


那么答案一定在20000附近。

再简单修正即可。

因此：

**会估算的人，比会计算的人更快。**

## 五、凑整法的核心思想

请牢记一句话：

> **先算简单的，再修正复杂的。**

不要一开始就想着精确。

先得到一个容易计算的结果。

再把误差补回来。

这就是所有速算技巧的底层逻辑。

# 第二节 凑整法的数学原理

很多同学会担心：

> “把数字改掉，不就算错了吗？”

不会。

因为凑整法建立在小学就学过的乘法分配律之上。

例如：

```
198×37
```

把198写成：

```
200-2
```

于是：

```
(200-2)×37
```

根据乘法分配律：

```
200×37

-

2×37
```

得到：

```
7400-74

=7326
```

这就是凑整法。

并不是近似计算。

而是**等价变形**。

---

再例如：

```
503×28
```

把503写成：

```
500+3
```

得到：

```
500×28

+

3×28
```

计算：

```
14000+84

=14084
```

依然完全正确。

---

因此：

> **凑整不是估算，而是把难算变成容易算。**

---

## 一般公式

如果：

```
A=N+d
```

其中：

```
N

是整十、整百、整千……

d

是很小的数字
```

那么：

```
A×B

=(N+d)×B

=N×B+d×B
```

如果：

```
A=N-d
```

那么：

```
A×B

=N×B-d×B
```

这就是所有凑整法的统一公式。

---

## 为什么优先修改接近整数的那个数？

例如：

```
398×53
```

398距离400只有2。

53距离50有3。

优先修改398：

```
400×53

减去

2×53
```

因为：

```
2×53
```

比：

```
398×3
```

简单得多。

原则是：

> **谁离整数最近，就先改谁。**

# 第三节 四大凑整模型

实际考试中，99%以上的凑整，都可以归纳为四种模型。

掌握这四种模型，几乎所有基础速算都能套用。

---

# 模型一：向上凑整（★★★★★）

特点：

数字略小于整数。

例如：

```
198

298

398

49

99

999
```

统一思路：

```
198

↓

200-2
```

例题：

```
198×24
```

计算：

```
200×24

=4800

减去

2×24

=48

答案：

4752
```

---

练习：

```
397×18
```

思路：

```
400×18

减

3×18
```

答案：

```
7146
```

---

# 模型二：向下凑整（★★★★★）

特点：

数字略大于整数。

例如：

```
201

301

501

1002
```

统一思路：

```
201

↓

200+1
```

例题：

```
201×43
```

计算：

```
200×43

+

43

=8643
```

---

练习：

```
502×19
```

计算：

```
500×19

+

2×19

=9500+38

=9538
```

---

# 模型三：双向凑整（★★★★★）

两个数字都接近整数。

例如：

```
398×51

497×203

998×999
```

这类题是十字修正法的基础。

例如：

```
398×51
```

第一步：

```
400×50

=20000
```

然后：

```
+400

-100

-2
```

答案：

```
20298
```

本章只要求理解这种思想。

第三章会系统讲解完整方法。

---

# 模型四：连续凑整（★★★★☆）

有些数字需要连续两次修正。

例如：

```
996×48
```

可以这样想：

```
1000×48

减去

4×48
```

得到：

```
48000

-192

=47808
```

再例如：

```
1998×13
```

思路：

```
2000×13

减

2×13
```

得到：

```
26000

-26

=25974
```

连续凑整最大的优点是：

无论数字多大，都能快速转换成整数计算。

---

# 本节总结

请记住以下四个核心原则：

1. **看到接近整十、整百、整千的数字，第一反应就是凑整。**
2. **凑整不是估算，而是利用乘法分配律进行等价变形。**
3. **优先修改距离整数最近的那个数，修正量越小越好算。**
4. **四种模型（向上凑整、向下凑整、双向凑整、连续凑整）覆盖了绝大多数基础速算题型，是后续所有技巧的基础。**
